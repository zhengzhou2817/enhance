# 贪吃蛇 Snake Game

一个使用原生 HTML、CSS、JavaScript 编写的贪吃蛇小游戏。仓库不依赖构建工具，下载后可直接运行，也可以部署到 GitHub Pages。

## 功能

- Canvas 游戏渲染
- 键盘方向键 / WASD 控制
- 空格键开始或暂停
- 移动端虚拟方向键
- 三档速度难度
- 分数、最高分、本地保存
- 暂停、重开、游戏结束状态
- 响应式布局，兼容桌面和手机
- GitHub Actions Pages 部署配置

## 本地运行

双击 `index.html` 即可。

## GitHub Pages

仓库推送成功后，如果 Pages 没有自动开启，请进入：

```text
Settings → Pages → Build and deployment → Source: GitHub Actions
```
